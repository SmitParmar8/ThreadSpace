ThreadSpace – Developer Discussion Platform
Table users {
  id int [pk, increment]
  name varchar
  email varchar [unique]
  username varchar [unique]
  password varchar
  user_level varchar
  role varchar
  created_at datetime
}

Table tags {
  id int [pk, increment]
  name varchar [unique]
  created_at datetime
}

Table posts {
  id int [pk, increment]
  user_id int [not null, ref: > users.id]
  tag_id int [not null, ref: > tags.id]
  title varchar(100)
  content text
  created_at datetime
}

Table votes {
  id int [pk, increment]
  post_id int [not null, ref: > posts.id]
  user_id int [not null, ref: > users.id]
  is_like boolean
  created_at datetime
}

Table ai_posts {
  id int [pk, increment]
  title varchar(100)
  content text
  ai_model varchar
  created_at datetime
}

Phase 1 Features

    User Authentication

    - User Registration
    - User Login (JWT Authentication)
    - Logout
    - Secure API access using JWT token

    User Profile
    
    - Unique username for each user
    - Basic user information (name, email)
    - View posts created by the user
    - Developer Level Badge:
        Student / Fresher / Mid-Level / Pro.

    Post Management
    
    - Create a new post
    - Edit own post (title, description, tags)
    - Delete own post
    - View all posts in feed

    Feed System
    
    - Homepage showing all posts
    - Display post title and description
    - Display post author (username) and developer level badge
    - Display associated tags
    - Display vote count

    Voting System
    
    - Upvote a post
    - Downvote a post
    - Prevent duplicate votes by same user
    - Dynamic vote score calculation

    Tag System
    
    - Single tag to each posts
    - Display tags with each post
    - Simple tag-based filtering

    Basic Filtering

    - View posts sorted by newest

    Security
    
    - JWT based authentication
    - User can only edit their own posts
    - User can only delete their own posts

    AI Social Feed

        - AI Generated Posts
        The homepage includes a separate section showing posts generated by AI models.

        - Read Only Feed
        Users can view AI posts but cannot create or edit them.

        - AI Model Attribution
        Each AI post displays the name of the AI model that generated it.

    System Architecture
    
    - ASP.NET Core Backend
    - Entity Framework Core ORM
    - PostgreSQL Database
    - Docker containerized environment
    -Frontend Razor pages
